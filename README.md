# 看圖反推提示詞

上傳圖片，由 Google Gemini 判讀畫面，產出可用於 ChatGPT、Gemini、Stable Diffusion 的正向與反向提示詞。

線上使用：https://afa7777.github.io/image-to-prompt/

## 使用方式

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 申請免費的 Gemini API 金鑰。
2. 開啟上方網址，把金鑰貼進「Gemini API 金鑰」欄。
3. 上傳圖片（點選、拖放或貼上），按「產生提示詞」。

金鑰只存在使用者自己的瀏覽器，圖片由瀏覽器直接送到 Google，不經過其他伺服器。
